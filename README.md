## 🔧 Featured Project

### Motor Maintenance & Monitoring System

A Python-based rule-driven motor condition monitoring system developed as my **CS50P Final Project**.

The system:

- Validates motor sensor data
- Monitors temperature, vibration, current, and RPM
- Detects abnormal motor conditions
- Classifies motor condition as `NORMAL`, `WARNING`, or `CRITICAL`
- Generates rule-based maintenance recommendations
- Calculates sensor statistics
- Tracks maintenance history
- Provides an interactive command-line interface

**Technologies:** Python · OOP · CSV · pytest · Rich

[View Project](https://github.com/Ahmed-Hisham-ML/predictive-maintenance-system)

[View V1.0.0 Release](https://github.com/Ahmed-Hisham-ML/predictive-maintenance-system/releases/tag/v1.0.0)
